# EduBridge AI

EduBridge AI is a monorepo containing a full-stack assessment and career recommendation platform.

## Architecture
- **Frontend**: Next.js 14 App Router, TypeScript, Tailwind CSS, Auth.js v5
- **Backend**: Node.js + Express + MongoDB (TypeScript)
- **AI Service**: Python FastAPI + Ollama
- **Workflow Automation**: n8n

## Getting Started
Please see the `README.md` inside each service's folder for setup and startup instructions.
